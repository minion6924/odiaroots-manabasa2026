Judge & Admin Passwords

Logins are real accounts managed in Supabase, so passwords can no longer be changed from this page. To change one, open your Supabase project → SQL Editor and run the "change password" command from your docs folder (ask Om if unsure). Change the judge password after judging ends.

The database itself checks your login on every request, so participant details and scores are protected even if someone bypasses this page.

Email Confirmations

Email sending is prepared but inactive. On-screen Entry ID confirmation is the active method. When a provider (e.g. Resend) is chosen, it will be connected through securely stored secrets on a server-side proxy — never an API key in this site's code.
